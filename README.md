## ◈ FEATURED PROJECTS

### 01. CivConnect — AI-Powered Grievance Management System

<kbd>🏆 Hackathon Winner — IIITM Gwalior</kbd> <kbd>AI/ML</kbd> <kbd>Web Development</kbd>

An AI-powered grievance management platform designed to streamline public complaint handling by making grievance registration, classification, and prioritization more efficient.

**Key Features**
- AI-assisted classification of grievances based on their content.
- Intelligent prioritization to help identify critical complaints.
- Centralized grievance management workflow.
- User-friendly web interface for submitting and tracking complaints.

**Achievement:** Developed as part of the winning hackathon project at IIITM Gwalior with Team **NanoNexus-0_0-**.

**Live Demo:** [CivConnect](https://grievance-triage-zeta.vercel.app/)

---

### 02. Carbon Dot Characterizer & Heavy Metal Detector

<kbd>Research Project</kbd> <kbd>Machine Learning</kbd> <kbd>Explainable AI</kbd>

An AI-driven research project focused on characterizing carbon dots and detecting heavy metals using their fluorescence properties. The system aims to transform experimental spectral data into meaningful analytical insights through data processing and machine learning.

**Key Features**
- Uploading and processing experimental spectral datasets.
- Automated identification and characterization of spectral data.
- Fluorescence-based heavy metal detection.
- Machine learning integration for predictive analysis.
- Explainable AI to improve model interpretability and transparency.
- Visualization of analytical results through an interactive dashboard.

**Technology Stack:** Python, Streamlit, Pandas, NumPy, Matplotlib, Machine Learning, Explainable AI.

---

### 03. Event Management System

<kbd>Full-Stack Development</kbd> <kbd>Database Management</kbd>

A full-stack web application designed to simplify academic event organization and participation by providing separate interfaces and authentication systems for students and faculty.

**Key Features**
- Separate login and authentication for students and faculty.
- Dedicated student and faculty dashboards.
- Event creation and management functionality.
- Student event registration workflow.
- MySQL database integration for managing application data.

**Technology Stack:** Node.js, MySQL, JavaScript, HTML5, CSS3.
